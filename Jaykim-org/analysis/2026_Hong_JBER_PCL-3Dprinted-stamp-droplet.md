## 1. 한 줄 요약
DLP 3D 프린팅 스탬프로 PCL을 hot embossing하고 PCL–PCL을 열풍(150 °C, 30–50 s)으로 직접 접합하여, 클린룸·포토리소그래피·접착필름 없이 수동 음압(일회용 주사기)으로 water-in-oil 액적을 생성하는 서브밀리 유체소자를 제작하였다.

## 2. 문제 정의와 기여
- **기존 한계**: PDMS 소프트리소그래피는 클린룸·SU-8 마스터가 필요. 선행 PCL 연구(Fan et al.)는 SU-8 몰드 + 이종 접착필름 밀봉에 의존.
- **기여 3가지**: (1) SU-8 없이 DLP 스탬프만으로 채널 구현, (2) 이종 재료 없이 PCL–PCL 열풍 직접 접합, (3) 표면처리 없이 PCL 고유 소수성으로 액적 생성.

## 3. 제작 공정 (재현용 파라미터)
| 단계 | 조건 |
|---|---|
| CAD/프린팅 | Fusion 360 → STL → Anycubic Photon Mono X (DLP, XY 50 µm / Z 10 µm). IPA 세척 후 405 nm UV 5 min 후경화 |
| PCL 성형 | PCL (Mw ~80 k, Sigma) 펠렛 70 ± 5 °C 오븐 10 min → Ø35 mm × 3 mm 디스크 |
| Hot embossing | 연화 PCL을 패턴/평판 스탬프에 10–15 N 수동 압착, 상온 10 min 냉각 후 분리 |
| 포트 | 1.5 mm biopsy punch, 입구 2 + 출구 1 |
| 접합 | 열풍기 150 °C, 거리 5 cm, **30–50 s** → 탭핑 후 60 × 60 mm 평판 + 1 kg 추 30 min (≈2.7 kPa) |
| 채널 | 폭 1000 µm × 높이 500 µm, 총 길이 117 mm, R ≈ 7.7 × 10⁹ Pa·s/m³ |

## 4. 핵심 결과
| 평가 항목 | 결과 |
|---|---|
| 형상 재현성 | PCL vs PDMS 폭/높이 차이 없음(p > 0.05). 실용 하한 폭 **400 µm** (200 µm는 단면 불완전). 단면은 DLP staircase로 사다리꼴 |
| 접합 윈도우 | ≤20 s: 100 µL/min에서 즉시 누수. 30–50 s: 3000 µL/min까지 무누수. ≥60 s: 단면 변형 |
| 접촉각 | 101.9 ± 3.93° (CV 3.86%, n = 5) → 소수성, 표면처리 불필요 |
| 액적 생성 | 음압 71.5 / 26.8 / 11.9 kPa → 0 / **5** / 0.5 drops/s. 26.8 kPa에서 526 ± 73 µm (CV 13.9%, n = 100) |
| 유동 영역 | Ca ≈ 4.2 × 10⁻³ (26.8 kPa) → squeezing regime. 고음압 thread-like flow는 유량비(Qd/Qc) 증가로 해석 |

## 5. 저자가 밝힌 한계
- DLP 해상도(50 µm) → 채널 폭 ≥400 µm, 진정한 마이크로플루이딕(<100 µm) 불가.
- 열풍 공정 윈도우가 좁고(30–50 s) 수동 공정 → 재현성 정량화 부족(단일 소자 100 액적, 소자 간 편차 미평가).
- PCL 광학 특성 → 형광 정밀분석 시 검토 필요. 소수성 표면의 비특이 흡착 → BSA/PEG 코팅 필요 가능.
- Ca는 초기 최대 음압과 문헌 물성으로 추정, 실제 유량 미측정. 음압이 시간에 따라 감소해 정상상태 아님.

## 6. 비판적 검토 (우리 연구실 관점)
1. **통계 설계**: n = 5 형상 측정, 단일 소자 액적 분석. 임상용 소자 개발 시 소자 간(inter-device) CV, 배치 간 재현성, 접합 강도 정량(burst pressure, 인장) 필요.
2. **압력 스케일 불일치**: 채널 예상 압력강하 ≤0.4 kPa vs 인가 음압 12–72 kPa. 대부분의 압력이 튜빙·니들·계면에서 소모됨 → 실제 구동 압력 측정(인라인 압력센서) 필요.
3. **PCL 생분해성의 진단 활용**: 논문은 "생분해성 일회용 POCT"를 언급하나 검증 없음. 체액(혈액, 활액) 접촉 시 단백질 흡착·용혈·분해 거동 데이터가 없음.
4. **온도 제어**: 열풍기 수동 → 온도 제어 핫플레이트/핫프레스로 대체하면 윈도우 확장 가능(저자도 계획).

## 7. 우리 연구실 연계 포인트
- **장비 접근성**: 데스크톱 DLP 프린터(~50만 원대) + 열풍기 + 오븐만으로 소자 제작 가능 → 임상 현장(외래·수술실) 근접 제작, 개발도상국 협력 연구에 적합.
- **미량 시료 진단**: 폭 400–1000 µm 채널은 수 µL 전혈·활액·기관지폐포세척액(BALF) 처리에 충분. 액적 크기 ~500 µm(≈70 nL)는 액적당 면역분석·LAMP 반응기로 활용 가능.
- **동물실험 연계**: 랫/마우스 반복 채혈량 한계(마우스 <100 µL/주) → 저용량 소자가 종단 바이오마커 모니터링에 유리. 연구실 보유 PHMG 기관내 주입 폐독성 모델과 결합 가능.
- **규제**: PCL은 FDA 승인 이력(임플란트·봉합사) 있는 재료 → 체외진단 소모품 생체적합성(ISO 10993) 논거 확보 용이.

## 8. 후속 연구 아이디어 (요약, 상세는 주간 제안서 참조)
1. 온도 제어 핫프레스 기반 PCL 접합 공정 윈도우 정량화 + burst pressure 데이터셋 구축.
2. PCL 소자 위 액적 기반 digital immunoassay / dd-LAMP로 마우스 전혈 3–5 µL 사이토카인 절대정량.
3. 고해상도 프린터(LCD 22 µm, PµSL 2–10 µm)로 하한 폭 100–200 µm 달성 여부 검증.
4. PCL 생분해성을 이용한 "사용 후 퇴비화 가능" POCT 카트리지의 체액 접촉 안정성 평가.
